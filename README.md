# 🎬 Viral Video — Telegram Bot + Mini App

ইউজার Mini App-এ ভিডিও বাছবে → Monetag-এর Rewarded Interstitial এড দেখবে → এড `valued` হলে ভিডিও আনলক হবে → ভিডিও চলবে। অ্যাডমিন বটে ভিডিও পাঠিয়েই আপলোড করবেন।

কোডে শুধু Python-এর নিজস্ব লাইব্রেরি ব্যবহার হয়েছে — আলাদা কিছু ইনস্টল লাগবে না।

---

## ⚠️ সবার আগে — নিরাপত্তা (১ মিনিট)

আগের চ্যাটে বটের টোকেন লেখা হয়েছিল। **ওই পুরনো টোকেন প্রোডাকশনে ব্যবহার করবেন না।**

1. Telegram-এ **@BotFather** খুলুন
2. `/revoke` চাপুন → আপনার বটটি বাছুন → নতুন টোকেন নিন
3. নতুন টোকেনটি **কাউকে পাঠাবেন না, চ্যাটে লিখবেন না** — শুধু নিচের ধাপ ৪-এর বাক্সে বসাবেন

## ধাপ ১ — আপনার Telegram ID নিন

1. Telegram-এ **@userinfobot** খুলুন, `/start` দিন
2. যে সংখ্যাটা (ID) দেখাবে, সেটাই আপনার **ADMIN_ID** — লিখে রাখুন

## ধাপ ২ — Monetag সেটআপ (পরে করলেও চলবে)

> Monetag ছাড়াও বট চলবে — তখন **টেস্ট মোডে** থাকবে (৩ সেকেন্ডের নকল এড দিয়ে পুরো ফ্লো টেস্ট করা যাবে)। আসল এডের জন্য:

1. [Monetag](https://www.monetag.com/)-এ অ্যাকাউন্ট খুলুন
2. ড্যাশবোর্ডে **Telegram Mini Apps** ট্যাবে আপনার অ্যাপ যোগ করুন (আগে বট বানানো থাকতে হবে)
3. **"Get SDK"** বাটনে চাপুন — এখান থেকে দুটো জিনিস পাবেন:
   - **Main Zone ID** (সংখ্যা) → এটাই `MONETAG_ZONE_ID`
   - **SDK script URL** → এটাই `MONETAG_SDK_URL`
4. Monetag-এ **Postback URL** চাইলে বসান: `https://আপনার-Render-লিংক/api/monetag-postback` (এটা শুধু হিসাব রাখার জন্য, না বসালেও এড চলবে)

## ধাপ ৩ — GitHub-এ ফাইল তুলুন (ফোনের ব্রাউজারেই হবে)

1. ফোনের ব্রাউজারে **github.com** খুলে ফ্রি অ্যাকাউন্ট করুন (থাকলে লগইন)
2. **New repository** বানান (নাম: `viral-video-bot`, Public)
3. এই প্রজেক্টের সব ফাইল আপলোড করুন: `main.py`, `webapp/` ফোল্ডার, `render.yaml`, `requirements.txt`, `.env.example`, `.gitignore`, `README.md`
   - ফোন থেকে: রিপোজিটরি পেজে **Add file → Upload files**
   - ⚠️ `videos.json` আর `.env` কখনো আপলোড করবেন না (এগুলো `.gitignore`-এ আছে)

## ধাপ ৪ — Render-এ চালু করুন

1. **render.com**-এ GitHub দিয়ে লগইন করুন
2. **New → Web Service** → আপনার `viral-video-bot` রিপোজিটরি বাছুন
3. **Free** প্ল্যান বাছুন, Start Command-এ লেখা থাকবে `python3 main.py`
4. **Environment Variables** পেজে বাক্সে বাক্সে বসান:
   - `BOT_TOKEN` = নতুন টোকেন (ধাপ ০ থেকে)
   - `ADMIN_ID` = আপনার Telegram ID
   - `WEBAPP_URL` = আপাতত ফাঁকা রাখুন
   - `MONETAG_ZONE_ID`, `MONETAG_SDK_URL` = থাকলে বসান, না থাকলে ফাঁকা
5. **Deploy** দিন। Deploy শেষ হলে Render একটা লিংক দেবে, যেমন `https://viral-video-bot.onrender.com`
6. ওই লিংকটা আবার **Environment Variables**-এ `WEBAPP_URL` হিসেবে বসিয়ে **আবার Deploy** দিন
7. **@BotFather**-এ যান → আপনার বট → **Bot Settings → Menu Button** → ওই লিংকটা বসান। এখন বটের Menu বাটনে চাপ দিলেই Mini App খুলবে।

## ধাপ ৪ (বিকল্প) — PythonAnywhere-এ চালু করুন (কার্ড লাগে না)

Render কার্ড চায় বলে এই পথটি কার্ড ছাড়াই চলে। এখানে বট **webhook মোডে** চলবে — অর্থাৎ Telegram মেসেজ এলে নিজে বটকে ডেকে জাগাবে, তাই সার্ভিস ঘুমিয়ে থাকলেও বট উত্তর দেবে।

1. **pythonanywhere.com**-এ ফ্রি (Beginner) অ্যাকাউন্ট করুন — কার্ড লাগে না। একটা ইউজারনেম বাছুন (যেমন আপনার নামের মতো কিছু)।
2. **Web** ট্যাবে **Add a new web app** → **Manual configuration** → Python 3.10 (বা নতুন) বাছুন।
3. **Bash console** খুলে লিখুন: `git clone https://github.com/abidofficial85/viral-video-bot`
4. **Web** ট্যাবে **WSGI configuration file** খুলুন, ভেতরের সব মুছে এই প্রজেক্টের `pythonanywhere_wsgi_snippet.py` ফাইলটির লেখা বসান — শুধু তিন জায়গা বদলাবেন: `USERNAME` (আপনার PythonAnywhere ইউজারনেম), `PASTE_FRESH_BOT_TOKEN_HERE` (নতুন টোকেন), `PASTE_ADMIN_ID_HERE` (আপনার Telegram ID)।
5. **Reload** (সবুজ বাটন) চাপুন। আপনার সাইটের লিংক হবে `https://USERNAME.pythonanywhere.com`।
6. **@BotFather**-এ যান → আপনার বট → **Bot Settings → Menu Button** → ওই লিংকটা বসান।
7. Webhook ঠিক বসেছে কিনা দেখতে ব্রাউজারে `https://USERNAME.pythonanywhere.com/api/setup-webhook` খুলে POST করুন (না হলে Reload-ই যথেষ্ট — চালুর সময় webhook নিজে বসে যায়)।

⚠️ PythonAnywhere ফ্রি-তে বাইরের নেটওয়ার্ক সীমিত — তাই কোডে `TG_PROXY=http://proxy.server:3128` বসানো আছে, এটা বদলাবেন না।

## ধাপ ৫ — টেস্ট করুন

1. বটে `/start` দিন — ভিডিও লিস্ট আসবে (প্রথমে খালি থাকবে, এটাই স্বাভাবিক)
2. **অ্যাডমিন হিসেবে বটে একটা ভিডিও পাঠান**, caption-এ টাইটেল লিখুন → "ভিডিও যোগ হয়েছে" মেসেজ আসবে
3. আবার `/start` দিন → ভিডিওটি দেখা যাবে → বাছুন → **"এড দেখে ভিডিও দেখুন"** চাপুন
   - টেস্ট মোডে: ৩ সেকেন্ডের নকল এড → ভিডিও চলবে
   - Monetag বসানো থাকলে: আসল ফুল-স্ক্রিন এড → এড শেষ হলে ভিডিও চলবে
4. অ্যাডমিন প্যানেল দেখতে বটে `/admin` লিখুন (ভিডিও সংখ্যা, ভিউ, ডিলিট)
5. ব্যাকআপ নিতে `/admin` থেকে `/export` লিখুন — `videos.json` ফাইলটি পাবেন, সেটা সেভ করে রাখুন

## ⚠️ ফ্রি হোস্টিংয়ের সীমা (আগে থেকে জেনে রাখুন)

- **Render ফ্রি সার্ভিস ১৫ মিনিট কেউ না এলে ঘুমিয়ে যায়** — পরের ভিজিটর এলে চালু হতে ~১ মিনিট লাগে। এ সময় বটও উত্তর দেবে না। (polling মোডে)
- **PythonAnywhere-এ webhook মোডে** ঘুমিয়ে থাকলেও Telegram মেসেজ এলে সার্ভিস জেগে ওঠে — বট উত্তর দেবে, তবে প্রথম উত্তরে কয়েক সেকেন্ড দেরি হতে পারে।
- **ভিডিওর লিস্ট (`videos.json`) রিস্টার্ট/রিডিপ্লয়ে মুছে যেতে পারে** — তাই নিয়মিত `/export` দিয়ে ব্যাকআপ রাখুন। ব্যাকআপ ফেরাতে ওই `videos.json` ফাইলটি বটে পাঠিয়ে দিন (শুধু অ্যাডমিন পারবেন)।
- ভিডিও ফাইলগুলো Telegram-এই থাকে (file_id দিয়ে), তাই সার্ভার থেকে মুছবে না — শুধু লিস্টের ব্যাকআপটা দরকার।
- স্থায়ীভাবে চালাতে পরে ছোট একটা VPS নিতে হবে।

|---|---|
| বট উত্তর দিচ্ছে না | Render-এ `BOT_TOKEN` ঠিক আছে কিনা দেখুন; সার্ভিস ঘুমিয়ে থাকলে ১ মিনিট অপেক্ষা করুন |

| "লিংকের মেয়াদ শেষ" | ভিডিও লিংক একবারই চলে, ১০ মিনিটের মধ্যে — আবার এড দেখুন |

## এটা কীভাবে কাজ করে (সংক্ষেপে)

- ইউজার আসল Telegram ইউজার কিনা — সার্ভার `initData` সিগনেচার যাচাই করে
- এডের রিওয়ার্ড শুধু `reward_event_type = valued` হলেই মেলে (Monetag-এর নিয়ম)
- ভিডিও লিংক একবার ব্যবহারের, ১০ মিনিটের মেয়াদ — কেউ লিংক শেয়ার করলেও দ্বিতীয়বার চলবে না
- Monetag-এর পোস্টব্যাক (সার্ভার-সাইড কনফার্মেশন) `postbacks.log`-এ জমা হয়
